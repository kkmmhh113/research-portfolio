## 시작한 이유

딥러닝을 처음 공부할 때 이미지 분석에 관심이 생겨, 공개 데이터로 직접 분류 모델을 학습시켜 보고 싶었습니다. DermaMNIST를 선택하고, 제한된 연산 자원에서 여러 설정을 시도하기 위해 비교적 가벼운 MobileNetV2를 사용했습니다.

## 시도한 내용

제가 해 본 부분은 학습을 실행하고 설정을 바꿔 보며 결과를 살펴보는 것이었습니다. 학습 코드 작성과 세부 기법을 적용하는 과정에는 AI 도구의 도움을 많이 받았습니다. 사전 학습된 MobileNetV2의 분류층을 7개 범주에 맞게 바꾸고 전체 모델을 미세 조정하는 코드로 시작했습니다.

학습 중 검증 손실이 가장 낮은 시점과 정확도가 가장 높은 시점이 항상 같지는 않았습니다. 서로 다른 시점에 저장한 모델 가중치(체크포인트)로 예측한 결과를 합치면 어떨지 궁금해 앙상블을 시도했습니다. 학습률과 가중치 감쇠를 여러 조합으로 바꿔 보기 위해, 학습 설정을 자동으로 탐색하는 도구인 Optuna도 사용했습니다.

| 시도 | 살펴보려던 것 |
| --- | --- |
| 기본 학습 | 사전 학습 모델을 새 분류 문제에 맞춰 학습하는 과정 |
| 체크포인트 앙상블 | 여러 시점에 저장한 모델의 출력을 평균했을 때의 결과 |
| Optuna 탐색 | 학습률과 가중치 감쇠 설정에 따른 결과 차이 |

## 이 경험에서 이어진 관심

이미지를 입력해 예측하고, 손실을 계산해 가중치를 갱신한 뒤 검증하는 과정을 처음 접한 프로젝트였습니다. 여러 설정을 바꿔 보는 과정에서, **어떤 설정이 결과에 영향을 주었는지 알려면 나머지 비교 조건을 같게 해야 한다**고 느꼈습니다.

당시에는 앙상블과 설정 조정으로 큰 성능 향상을 얻지 못했던 것으로 기억합니다. 이후 AI 도구의 도움을 받아 코드를 검토·정리하는 과정에서 체크포인트 관리 문제가 확인되어 저장 방식을 수정했습니다. 당시 가중치와 비교 기록이 충분히 남아 있지 않고 수정한 코드로 재학습하지 않아, 현재는 성능 수치보다 시도한 과정과 학습 코드를 중심으로 정리했습니다.

다시 실험한다면 단일 모델의 결과를 먼저 남기고, 같은 조건에서 설정을 하나씩 바꾸며 비교하고 싶습니다. 세부 학습 설정과 재실험 전에 확인할 내용은 [학습 과정](project-notes.ko.md)에 적었습니다.
