# DermaMNIST 이미지 분류 모델

**2025 · 개인 프로젝트 · 모델 학습 경험**

딥러닝에 공부하던 초기에는 잠깐 이미지 분석에 관심이 있었고 공개 데이터셋을 활용할 수 있어 첫 딥러닝 프로젝트로 DermaMNIST를 선택했습니다.

[프로젝트 기록](project-notes.ko.md) · [기본 학습 코드](notebooks/dermamnist_baseline.ipynb) · [Optuna 탐색 코드](notebooks/dermamnist_optuna.ipynb)

## 시도한 내용

제한된 연산 자원에서 여러 학습 설정을 시도하기에 적합하다고 생각해 가벼운 구조의 MobileNetV2를 선택했습니다. 과적합을 방지하기 위해 학습률 스케줄러를 포함했고, 최적화 알고리즘으로 AdamW를 사용했습니다.

학습을 시도하던 중 에포크별 검증 손실과 정확도를 확인하면서 손실이 가장 낮은 체크포인트와 정확도가 가장 높은 체크포인트가 항상 같지는 않다는 점을 확인했습니다. 저장된 체크포인트를 결합하는 앙상블을 시도했고, 하이퍼파라미터 설정을 비교하기 위해 Optuna도 사용했습니다.

| 항목 | 사용한 학습 설정 |
| --- | --- |
| 모델 | ImageNet 사전 학습 MobileNetV2, 7개 범주 분류층 |
| 최적화 알고리즘 | AdamW |
| 학습률 스케줄러 | 기본 학습 코드: CosineAnnealingLR / Optuna 탐색 코드: CosineAnnealingWarmRestarts |
| 앙상블 | 동일한 모델 구조에서 선택한 에포크별 체크포인트의 로짓 평균 |
| Optuna 탐색 항목 | 특징 추출부 학습률, 분류층 학습률, 가중치 감쇠 |

학습 코드에는 데이터 증강, 클래스 가중치를 적용한 Focal Loss, Mixup도 포함했습니다. 사전 학습된 모델을 바탕으로 여러 학습 설정을 적용해 보는 과정이었습니다.

## 결과와 배운 점

당시에는 앙상블과 하이퍼파라미터 조정으로 큰 성능 향상을 얻지 못했던 것으로 기억합니다. 당시의 비교 기록과 Optuna 탐색 결과는 남겨놓지 않아 정확한 개선 폭을 다시 확인하기는 어렵습니다.

당시 실행 기록에는 테스트 앙상블 정확도 86.93%가 남아 있습니다. 다만 코드를 다시 정리하는 과정에서 체크포인트 순위를 관리하는 문제가 발견됐고, 당시 체크포인트 파일도 남아 있지 않습니다. 의도한 모델 조합으로 나온 점수인지 확인하기 어려워 이 수치는 과거 실행 기록으로만 남겼습니다. 현재 공개한 코드는 해당 문제를 수정한 버전이며, 아직 다시 학습을 시도하지 않았습니다.

이 프로젝트를 통해 예측, 손실 계산, 가중치 갱신, 검증 결과 확인으로 이어지는 학습 과정을 이해하게 되었습니다. 기법을 추가한다고 정확도가 자동으로 높아지지는 않으며, 체크포인트 관리 역시 신뢰할 수 있는 평가의 일부라는 점을 배웠습니다.
