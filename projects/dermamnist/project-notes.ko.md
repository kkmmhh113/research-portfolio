# 첫 딥러닝 프로젝트: MobileNetV2로 DermaMNIST 분류하기

## 시작한 이유

의료영상 분석에 관심이 있어 첫 프로젝트로 피부 병변 분류를 선택했습니다. DermaMNIST는 공개 데이터셋이라 접근하기 쉬웠고, 처음 이미지 분류를 시도하기에 적합하다고 생각했습니다.

## 모델과 학습 설정

모델은 MobileNetV2를 선택했습니다. 가볍고 빠른 모델이라 여러 설정을 바꿔 가며 학습하기에 적합하다고 생각했습니다. ImageNet으로 사전 학습한 모델의 마지막 분류층을 피부 병변 7종에 맞게 바꾸고, 전체 모델을 미세조정했습니다.

최적화 알고리즘은 AdamW를 사용했습니다. 학습률을 조절하기 위한 스케줄러도 처음부터 포함했습니다. 기본 학습 코드에는 CosineAnnealingLR, Optuna 탐색 코드에는 CosineAnnealingWarmRestarts를 사용했습니다.

## 앙상블을 시도한 이유

학습하면서 에포크별 검증 손실과 정확도를 확인했습니다. 손실이 가장 낮은 시점과 정확도가 가장 높은 시점이 달라서, 각 시점에 저장한 모델을 합쳐 보면 어떨까 생각했습니다. 성능을 더 높일 방법이 잘 떠오르지 않던 때라 앙상블을 시도했습니다.

결합한 것은 같은 MobileNetV2를 서로 다른 에포크에 저장한 체크포인트들입니다. 각 체크포인트에서 나온 로짓을 평균해 최종 클래스를 선택했습니다. 당시에는 단일 모델과 정확도가 거의 비슷해 큰 성능 향상을 느끼지 못했습니다. 다만 지금 남아 있는 파일만으로는 당시 단일 모델과 앙상블의 차이를 정확한 수치로 확인하기 어렵습니다.

## Optuna

하이퍼파라미터에 따른 결과를 그래프로 비교할 수 있다고 해서 Optuna도 사용해 보았습니다. 직접 값을 바꾸는 것보다 조정하기 편할 것 같았습니다. 코드에는 특징 추출부와 분류층의 학습률, 가중치 감쇠를 탐색하도록 설정했습니다.

당시에는 큰 성능 향상을 보지 못했던 것으로 기억합니다. Optuna 탐색 결과가 남아 있지 않아 최적 설정과 정확한 개선 폭은 다시 확인하기 어렵습니다. 기본 학습 코드와 Optuna 탐색 코드의 학습률 스케줄러도 달라서, 두 결과의 차이를 전부 Optuna의 효과로 해석하기는 어렵습니다.

## 배운 점

첫 프로젝트라 딥러닝 모델이 어떻게 학습하고 예측하는지 알아가는 과정이었습니다. 손실을 계산하고 가중치를 갱신하면서 정답에 가까워지는 방식을 배웠습니다. 직접 학습시킨 모델이 이미지를 분류하는 것을 보면서 ‘실제로 되는구나’라는 느낌을 받았습니다.

## 코드를 다시 정리하며 발견한 점

코드를 다시 정리하는 과정에서 정확도가 높은 체크포인트를 저장하는 방식에 문제가 발견됐습니다. 새 최고 점수가 나오면 이전 순위의 파일을 제대로 유지하지 못하는 구조였습니다. 현재 코드는 에포크마다 별도 파일을 저장하고, 정확도와 손실 기준으로 사용할 파일을 선택하도록 수정했습니다.

당시 실행 기록에는 테스트 앙상블 정확도 86.93%가 남아 있습니다. 하지만 체크포인트 파일이 없고 저장 방식에도 문제가 있었기 때문에, 의도한 모델 조합에서 나온 점수인지 다시 확인하기 어렵습니다. 현재 코드는 아직 다시 학습하지 않았으므로 이 점수는 과거 실행 기록으로만 남겼습니다.

이 페이지에는 2025년에 해본 시도와 2026년에 코드를 다시 정리하며 발견한 문제를 함께 기록했습니다. 당시의 실행 결과와 이후 수정한 코드의 상태를 구분해 두었습니다.
