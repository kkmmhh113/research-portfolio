# DermaMNIST · 학습 과정

[프로젝트 소개](README.md) &nbsp; · &nbsp; **학습 과정** &nbsp; · &nbsp; [기본 학습 코드](notebooks/dermamnist_baseline.ipynb) &nbsp; · &nbsp; [Optuna 코드](notebooks/dermamnist_optuna.ipynb)

2025년에 학습을 실행하고 설정을 바꿔 본 과정과, 2026년에 AI 도구의 도움을 받아 코드를 검토·정리한 내용을 기록했습니다. 당시 학습 코드 작성과 세부 기법의 적용에도 AI 도구를 많이 활용했습니다.

## 모델과 학습 설정

여러 설정을 바꿔 가며 학습해 보기 위해 비교적 가벼운 MobileNetV2를 선택했습니다. ImageNet 사전 학습 가중치를 사용하고 마지막 분류층을 7개 범주에 맞게 바꾼 뒤, 특징 추출부를 포함한 전체 모델을 미세 조정했습니다.

다음은 AI의 도움을 받아 구성한 코드에 담긴 설정입니다. 각 기법의 효과를 따로 검증한 목록은 아니며, 당시 시도한 학습 구성을 살펴보기 위해 정리했습니다.

| 항목 | 기본 학습 | Optuna 탐색 |
| --- | --- | --- |
| 최적화 알고리즘 | AdamW | AdamW |
| 학습률 스케줄러 | CosineAnnealingLR | CosineAnnealingWarmRestarts |
| 특징 추출부 학습률 | 0.0001 | 0.00001–0.0005 탐색 |
| 분류층 학습률 | 0.001 | 0.0005–0.005 탐색 |
| 가중치 감쇠 | 0.0005 | 0.0001–0.005 탐색 |
| 체크포인트 선택 | 검증 정확도 상위 3개 + 검증 손실 상위 1개 | 검증 정확도 상위 2개 + 검증 손실 상위 2개 |

코드에는 좌우·상하 반전, 회전, 색상 변형과 클래스 가중치를 적용한 Focal Loss, Mixup이 포함되어 있습니다. 두 코드 모두 30에포크, 배치 크기 64로 설정되어 있으며, 224 크기로 불러온 이미지를 336 × 336으로 변환합니다.

## 앙상블을 시도한 이유

학습 중 검증 손실이 가장 낮은 시점과 정확도가 가장 높은 시점이 달랐습니다. 각 시점에 저장한 모델을 합쳐 보면 어떨까 생각해, 체크포인트별 로짓을 평균한 뒤 최종 클래스를 선택하는 앙상블을 시도했습니다.

현재 코드는 정확도와 손실 기준에 같은 체크포인트가 모두 포함되면 그 출력을 두 번 반영하는 기존 방식을 유지합니다. 따라서 중복된 체크포인트는 평균에서 더 큰 비중을 갖습니다.

당시에는 단일 모델과 정확도가 크게 다르지 않았던 것으로 기억합니다. 다만 지금 남아 있는 파일만으로는 정확한 차이를 확인하기 어렵습니다.

## Optuna에서 비교하려던 것

학습률과 가중치 감쇠를 직접 바꾸는 것보다 여러 설정을 탐색하기 편할 것 같아 Optuna를 사용했습니다. 코드에서는 특징 추출부와 분류층의 학습률을 따로 탐색하고, 각 시도의 최고 검증 정확도로 설정을 선택합니다.

기본 코드와 Optuna 코드에는 **스케줄러와 체크포인트 선택 개수의 차이도 있습니다.** 따라서 결과가 달라져도 그 차이를 전부 하이퍼파라미터 탐색의 효과로 해석할 수는 없습니다. 같은 조건에서 한 요소씩 비교하는 과정이 필요합니다.

## 코드를 정리하며 확인한 내용

AI 도구와 함께 코드를 점검하는 과정에서 새 최고 점수가 나왔을 때 이전 순위의 체크포인트를 제대로 유지하지 못하는 문제가 확인되었습니다. 수정 코드도 AI의 도움을 받아 작성했으며, 현재는 에포크별로 파일을 저장하고 검증 정확도와 손실에 따라 사용할 파일을 선택합니다.

당시 체크포인트와 탐색 결과가 충분히 남아 있지 않고, 현재 코드로 재학습하지 않아 의도한 조합의 성능을 다시 확인하지 못했습니다. 정규화 값 역시 어떤 데이터 분할에서 구했는지 확인이 필요합니다.

현재 코드에서는 검증 데이터로 모델과 체크포인트를 선택하고 테스트 데이터는 마지막 평가에 사용합니다. 다만 이 테스트 데이터의 결과를 과거에도 확인했으므로, 재실행하더라도 새로운 평가 데이터에서 처음 얻은 결과로 해석하지는 않습니다.

## 이 경험에서 이어서 공부할 것

학습을 실행하고 모델이 이미지를 분류하는 것을 보며 딥러닝의 학습 과정을 구체적으로 접할 수 있었습니다. 여러 기법을 함께 적용해 본 만큼, 이제는 각 설정이 어떤 역할을 하는지 이해하고 결과의 차이를 설명하는 연습으로 이어 가고 싶습니다.

다시 실험한다면 단일 모델의 기준 결과부터 남기고, 같은 조건에서 앙상블이나 탐색 설정을 하나씩 비교하고 싶습니다. 결과 수치와 함께 사용한 설정·가중치·데이터 분할을 기록하는 습관도 갖추려 합니다.
