# 학습 코드 정리 기록

2025년에 사용한 학습 코드를 2026년에 다시 정리했습니다. 기존 코드는 별도로 보관하고, 현재 공개한 코드에서 달라진 부분을 기록했습니다.

## 변경 사항

- 에포크마다 별도 파일로 체크포인트를 저장하고, 사용할 파일을 목록으로 관리하도록 바꿨습니다. 기존 기본 학습 코드에서는 이전 순위의 체크포인트가 덮어써질 수 있었습니다.
- 앙상블 결합 방식이 로짓 평균임을 명확히 표시했습니다. 정확도와 손실 양쪽에서 선택된 체크포인트에는 두 표를 부여하는 기존 가중 규칙을 유지했습니다.
- 서로 다른 실험의 체크포인트가 섞이지 않도록 실행마다 별도 폴더를 사용했습니다.
- CUDA를 직접 지정하던 호출을 선택된 장치에 따라 텐서를 배치하는 방식으로 바꿨습니다.
- 기존 사전 학습 API와 일치하도록 ImageNet V1 가중치를 명시적으로 선택했습니다.
- 학습 라벨에서 클래스 가중치를 계산하고, 설정·체크포인트 선택·평가 지표를 기록하도록 했습니다.
- 테스트 평가를 학습 및 검증 과정과 분리했습니다.
- 긴 코드를 데이터 준비·학습·평가 단계로 나누고, 현재 코드의 실행 결과와 혼동하지 않도록 과거 실행 출력을 제거했습니다.

## 남아 있는 한계

현재 코드는 아직 다시 학습하거나 처음부터 끝까지 실행해 확인하지 않았습니다. 기존 정규화 값의 출처도 확인이 필요합니다. 당시 체크포인트와 Optuna 탐색 결과가 남아 있지 않아, 과거 테스트 정확도가 의도한 모델 조합의 결과인지 다시 확인하기는 어렵습니다.

테스트 데이터는 이미 결과를 확인한 상태입니다. 같은 데이터로 다시 실험하면 기존 결과를 본 뒤의 비교가 된다는 점도 기록해 둡니다.

기본 학습 코드와 Optuna 탐색 코드는 학습률 스케줄러도 다릅니다. 두 결과에 차이가 나더라도 하이퍼파라미터 탐색만의 효과로 해석하기는 어렵습니다.
