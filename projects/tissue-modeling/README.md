# 인체 디지털 트윈을 위한 조직 기반 모델링

**2026–현재 · 진행 중인 개인 프로젝트**

[모델 설명](MODEL.md) · [핵심 코드](model_sketch.py)

## 시작한 이유

조직별 모델을 연결하면 약물이 몸 안에서 어떻게 이동하고 반응하는지 살펴볼 수 있을 것 같아 시작했습니다. 인체 디지털 트윈이라는 큰 관심사에서 출발했지만, 현재는 여러 장기를 단순화한 약동학 모델을 이해하고 구성하는 데 집중하고 있습니다.

## 구상하고 있는 모델

생리학 기반 약동학(PBPK) 모델을 바탕으로 위장관, 혈액 순환, 간, 신장, 기타 조직을 연결합니다. 각 구획에 남아 있는 약물량을 계산하고, 혈류를 통한 이동과 대사·배설을 더해 시간에 따른 농도 변화를 살펴봅니다.

현재 코드는 위장관과 간을 여러 구간으로 나누어, 약물이 어디에서 이동하고 제거되는지 살펴보는 구성입니다. 조직을 연결하는 방식과 주요 가정은 [모델 설명](MODEL.md)에 정리했습니다.

저는 조직별 모델을 연결하는 방향을 제안했고, 구현과 분석에는 AI 도구를 활용했습니다. 현재는 모델에 사용된 방법을 관련 문헌과 함께 살펴보며, 주요 가정과 결과를 이해하는 데 집중하고 있습니다.

## 현재까지 해본 것과 남은 부분

지금까지는 공개된 사람의 약동학 데이터를 비교 대상으로 사용했습니다. 카페인과 파라세타몰에서는 예측한 농도 변화가 관측값과 비교적 가까운 경우가 있었지만, 에날라프릴과 대사체에서는 차이가 컸습니다. 약물마다 모델 구성이 달랐고, 모든 평가 조건을 만족한 것도 아니었습니다.

결과를 살펴보면서 모델 안의 약물량 계산이 일관되어도 실제 농도 예측은 틀릴 수 있다는 점에 관심을 갖게 되었습니다. 기전을 추가했을 때 오히려 예측이 나빠진 경우도 있어, 추가한 기전과 매개변수가 무엇을 의미하는지 더 이해하고 싶습니다.

앞으로는 매개변수의 의미와 출처를 더 명확히 정리하고, 예측이 잘 맞지 않은 이유를 살펴보고 싶습니다. 관측값이 혈장인지 혈청인지, 집단 평균인지 개인의 측정값인지도 맞춰 비교해야 합니다.

현재 작업은 단순화한 약동학 모델을 다루는 단계입니다. 전임상 데이터를 활용한 임상 결과 예측과 인체 디지털 트윈은 장기적으로 더 공부하고 싶은 방향입니다.
