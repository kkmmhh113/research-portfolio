# TissuePK — 조직별 약물 이동 모델링

**2026–현재 · 진행 중인 개인 학습 프로젝트**

[모델 설명](MODEL.md) · [핵심 코드](model_sketch.py)

## 시작한 이유

약물의 대사와 체내 이동을 수학적으로 설명한 논문을 읽으며, 조직별 모델을 연결하면 투여한 약물이 몸 안에서 어떻게 움직이는지 계산해 볼 수 있겠다고 생각했습니다. 이런 계산을 약물의 효과 예측까지 연결할 수 있을지도 궁금했습니다.

개인의 특성을 반영하는 인체 디지털 트윈에 장기적인 관심이 있지만, 현재는 우선 생리학 기반 약동학(PBPK) 모델을 구성하고 농도 변화를 살펴보는 작은 실습을 진행하고 있습니다. 참고한 에날라프릴 논문은 약동학과 약력학을 함께 다루며, 제가 시도한 범위는 주로 약동학 계산입니다.

## 어떤 자료와 비교했는지

비교 대상으로는 [PK-DB](https://academic.oup.com/nar/article/49/D1/D1358/5957165)에 수록된 사람의 카페인, 파라세타몰, 에날라프릴 약동학 자료를 사용했습니다. 투여량과 투여 경로, 측정 시점을 확인하고, 투여 후 시간에 따른 관측 농도와 모델이 계산한 농도 곡선을 비교했습니다. 에날라프릴에서는 원래 약물과 대사체인 에날라프릴라트를 구분해 살펴보았습니다.

이 자료를 참고한 이유는 농도를 계산하는 모델을 만들었을 때 실제 관측값과 어디서 차이가 나는지 확인해 보고 싶었기 때문입니다. 사람의 약동학 자료와 비교한 실습이며, 전임상 자료로 임상 결과를 예측한 작업은 아닙니다.

## 시도한 구성

위장관, 혈액 순환, 간, 신장, 기타 조직을 구획으로 나누고, 혈류에 따른 이동과 대사·배설을 계산해 시간에 따른 약물량과 농도를 구해 보았습니다. 위장관과 간을 여러 구간으로 나눈 구성도 살펴보았습니다.

조직을 연결하는 방향을 정하고, 코드 구현과 분석에는 AI 도구의 도움을 많이 받았습니다. [모델 설명](MODEL.md)에는 각 구획의 역할과 참고 문헌을, [핵심 코드](model_sketch.py)에는 장·간·신장에서 약물량이 달라지는 계산의 일부를 담았습니다.

## 해보면서 알게 된 점과 남은 부분

카페인과 파라세타몰에서는 관측 농도와 비교적 가까운 결과도 있었지만, 에날라프릴과 대사체에서는 차이가 컸습니다. 약물별로 모델 구성이 달랐고 모든 평가 조건을 만족한 것도 아니어서, 여러 약물의 반응을 잘 예측하는 모델을 만들었다고 말할 단계는 아닙니다.

모델 안에서 약물량의 계산이 일관되어도 실제 농도 곡선은 잘 맞지 않을 수 있었고, 기전을 추가했을 때 예측이 나빠진 경우도 있었습니다. 결과를 설명하려면 각 매개변수의 의미와 출처, 추가한 가정을 더 이해해야 한다고 느꼈습니다. 관측값이 혈장인지 혈청인지, 집단 평균인지 개인의 측정값인지도 맞춰 비교할 필요가 있습니다.

앞으로는 이 부분들을 정리하고 관측값과 차이가 나는 이유부터 살펴보고 싶습니다. 농도에서 약물의 효과를 예측하는 단계로 나아가려면 농도와 반응의 관계를 나타내는 별도의 모델과 검증 자료가 필요하므로, 약력학(PD)도 더 공부하려 합니다.
