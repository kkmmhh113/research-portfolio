# 분자 구조 기반 약물 반응 예측

**2026–현재 · 진행 중인 개인 프로젝트**

[모델 구조와 계산식](MODEL.md) · [핵심 코드](model_sketch.py)

## 시작한 이유

학습할 때 보지 못한 화합물도 분자 구조를 보고 생물학적 반응을 예측할 수 있을지 궁금해서 시작했습니다. 처음에는 폭넓은 약물 효과를 생각했지만, 활용할 수 있는 데이터를 살펴보면서 유전자 발현 변화로 범위를 좁혔습니다. 현재는 공개 SciPlex3 데이터의 A549, K562, MCF7 세포주를 중심으로 살펴보고 있습니다.

## 구상하고 있는 모델

같은 약물도 세포주나 처리 조건에 따라 반응이 달라진다고 보고, 다음 정보를 함께 사용하는 방향으로 진행하고 있습니다.

- **분자 구조:** 원자와 결합으로 표현한 분자 그래프와 분자량 등 물리화학적 특징
- **처리 맥락:** 세포주, 데이터셋, 용량, 처리 시간, 대조군의 발현 정보
- **예측 대상:** 약물을 처리한 세포와 대조군 사이의 유전자 발현 차이

앞선 실험에서는 분자 지문을 사용했고, 이후에는 분자·맥락·예측 대상을 나누어 표현하는 P/C/R 후보 모델을 구성했습니다. 현재 후보의 핵심 계산을 [설계 노트](MODEL.md)에 정리했습니다.

저는 분자 구조를 입력으로 사용하는 방향과 유전자 발현이라는 예측 대상을 정했습니다. 구현과 데이터·결과 점검에는 AI 도구를 활용했습니다. 현재는 모델이 정보를 결합하는 방식과 데이터 처리 과정을 공부하고 있습니다.

## 현재까지 해본 것과 남은 부분

기존 실험에서는 분자 구조와 조건 정보를 함께 사용한 모델이 조건별 평균 기준보다 높은 점수를 얻은 경우가 있었습니다. 다만 모든 시간 조건에서 개선된 것은 아니며, 이 비교만으로 분자 구조 입력의 기여를 따로 확인한 것도 아닙니다. 표적 정보를 추가한 개발 실험에서도 개선이 나타나지 않았습니다.

데이터를 다시 점검하면서 유전자 주석과 일부 화합물의 구조 매핑 문제를 확인했습니다. 따라서 과거 점수를 현재 후보 모델의 확정된 성능으로 제시하지 않고, 데이터 정의를 정리하는 일을 우선하고 있습니다. 현재의 그래프 기반 후보도 최종 모델로 선택된 상태는 아닙니다.

다음에는 데이터와 분자 구조의 대응을 정리한 뒤, 분자 정보를 추가하는 것이 새로운 화합물의 반응 예측에 실제로 도움이 되는지 확인하고 싶습니다.
