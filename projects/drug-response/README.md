# Mol2Expr — 분자 구조 기반 발현 변화 예측

**2026–현재 · 진행 중인 개인 학습 프로젝트**

[모델 설명](MODEL.md) · [핵심 코드](model_sketch.py)

## 시작한 이유

[LPM 논문](https://www.nature.com/articles/s43588-025-00870-1)을 읽으며 약물 처리에 따른 유전자 발현 반응을 예측하는 방법에 관심이 생겼습니다. 특히 학습한 약물 식별자에 대응하는 표현을 사용하는 구조에서, 학습에 없는 새로운 화합물을 어떻게 다룰 수 있을지가 궁금했습니다. 논문에서도 새로운 처리나 세포 유형으로 확장하려면 적절한 사전학습 표현이 필요하다는 한계를 설명합니다.

분자 구조를 입력하면 약물 사이의 공통점도 활용할 수 있지 않을까 생각해, 공개 데이터로 작은 모델을 구성해 보았습니다. 논문에서 얻은 아이디어를 바탕으로 모델 설계와 평가 방법을 공부하는 프로젝트입니다.

## 어떤 데이터를 다뤘는지

공개 SciPlex3 데이터의 A549, K562, MCF7 세포주를 중심으로 살펴보았습니다. 같은 세포주·약물·처리 조건에 해당하는 세포들의 발현을 모아 요약하고, 대응하는 대조군과의 차이를 예측 대상으로 삼았습니다. 현재 다루는 값은 조건별 평균 발현 변화입니다.

약물의 폭넓은 효과에 관심을 두고 시작했지만, 이 자료로 우선 살펴보려는 것은 약물 처리 후 발현의 변화입니다. 이 값만으로 실제 치료 효과나 안전성을 판단할 수는 없습니다.

## 시도한 구성

- **분자 정보:** 앞선 실험에서는 Morgan 분자 지문을 사용했고, 이후에는 원자와 결합을 그래프로 표현하는 방식도 살펴보고 있습니다.
- **세포와 처리 조건:** 세포주, 용량, 처리 시간과 대조군의 발현 정보를 함께 반영하려 했습니다.
- **출력:** 약물을 처리한 세포와 대조군 사이의 유전자별 발현 차이입니다.

프로젝트의 방향과 예측 대상을 정하고, 코드 구현과 분석에는 AI 도구의 도움을 많이 받았습니다. [모델 설명](MODEL.md)과 [핵심 코드](model_sketch.py)는 제가 시도한 구성의 흐름을 간략하게 보여줍니다.

## 해보면서 알게 된 점과 남은 부분

일부 실험에서는 같은 조건의 평균 반응을 사용하는 기준 모델보다 높은 점수가 나왔지만, 모든 조건에서 일관된 개선을 얻지는 못했습니다. 분자 구조 정보 자체가 새로운 화합물의 예측에 도움이 되었는지는 아직 확인해야 합니다. 표적 정보를 추가한 개발 실험에서도 개선이 나타나지 않았습니다.

자료를 정리하며 유전자 이름과 일부 화합물 구조의 연결에 문제가 있는 것도 확인했습니다. 이 대응 관계와 발현 변화의 계산 기준을 점검해야 하므로, 기존 점수를 현재 모델의 검증된 성능으로 제시하기는 어렵습니다.

결과가 기대와 다를 때 그 이유를 스스로 설명하는 데 어려움이 있었습니다. 분자 구조를 넣으면 도움이 될 것이라는 생각도 비교를 통해 확인해야 하는 가정이라는 점을 느꼈고, 모델의 학습 원리와 각 입력의 역할을 더 공부하고 있습니다.

앞으로는 데이터의 대응 관계를 먼저 정리한 뒤, 학습용과 평가용 약물을 나누고 분자 정보를 포함하거나 제외한 결과를 비교해 보고 싶습니다. 대조군 발현을 통해 세포 상태를 반영하는 방식과, 예측이 잘 맞지 않는 약물의 표적·관련 경로도 문헌과 함께 살펴보고 싶습니다.
