# Mol2Expr · 모델과 코드

[프로젝트 소개](README.md) &nbsp; · &nbsp; **모델과 코드 설명** &nbsp; · &nbsp; [코드 예시](model_sketch.py)

초기 분자 지문 모델 이후, **AI 도구의 도움을 받아 구성한 그래프 기반 후보 모델**의 흐름을 정리했습니다. 공개 코드는 이 구성의 계산 일부를 담은 예시이며, 그래프 기반 구성의 예측 성능은 아직 검증하지 않았습니다.

먼저 볼 부분은 **분자 구조와 처리 조건을 입력해, 대조군 대비 평균 발현 변화를 예측한다는 흐름**입니다. 아래 함수들은 그 흐름을 구현하기 위해 살펴본 계산들입니다.

## 전체 흐름

```mermaid
%%{init: {"flowchart": {"rankSpacing": 20, "nodeSpacing": 28}}}%%
flowchart TD
    A["원자 · 결합<br/>분자 특성"] --> P["분자 표현"]
    P --> D["용량에 따른<br/>특징 조절"]
    Dose["처리 용량"] --> D
    D --> C["세포 조건과 결합"]
    Context["세포주 · 처리 시간<br/>대조군 발현"] --> C
    C --> R["유전자별 출력"]
    R --> Y["대조군 대비<br/>평균 발현 변화"]
```

모델에서 구분하는 세 요소는 **약물 처리**(P), **실험 조건**(C), **예측할 유전자**(R)입니다. LPM의 구분 방식을 참고하되, 이 프로젝트에서는 화합물의 분자 구조를 입력하는 데 관심을 두었습니다.

## 코드에 담긴 구성

**1. 분자 구조에서 공통점 찾기**<br>
초기 실험의 Morgan 분자 지문과 달리, 이 후보 구성은 원자를 점(노드), 원자 사이의 결합을 선으로 나타낸 그래프를 사용합니다. 이웃 원자의 정보를 모아 특징을 만들고, 분자량 등 물리화학적 특성도 함께 사용하는 방식입니다.

**2. 용량과 세포 조건 반영하기**<br>
용량에 따라 분자 특징의 크기를 조절한 뒤, 세포 조건으로 특징의 크기와 값을 다시 조절합니다. 같은 약물이라도 처리 조건에 따라 다른 반응을 출력하도록 한 구성입니다. 코드의 용량 조절값은 모델이 학습하는 값이며, 실험에서 측정한 IC50이나 EC50을 의미하지는 않습니다.

**3. 유전자별 발현 변화로 바꾸기**<br>
조건별 평균 반응을 기준으로 약물별 차이를 학습하고, 출력을 대조군 대비 발현 변화의 척도로 되돌리는 구성입니다. 예측 대상은 같은 조건의 세포들을 모아 얻은 평균 발현 차이입니다.

## 공개 코드와 연결해서 읽기

[`model_sketch.py`](model_sketch.py)는 아래 계산을 발췌한 예시입니다.

| 코드 | 하는 일 |
| --- | --- |
| `GraphMessageLayer` | 결합 종류별로 이웃 원자의 정보를 모아 원자 특징 갱신 |
| `dose_gate` | 정규화된 용량에 따라 분자 특징의 크기 조절 |
| `condition_perturbation` | 세포 조건으로 특징의 크기와 값을 조절하는 FiLM 형태의 계산 |
| `factorized_readout` | 잠재 계수와 유전자 표현을 이용해 유전자별 출력 생성 |
| `restore_response` | 기준 반응과 표준화에 사용한 평균·척도를 반영해 발현 변화로 복원 |

원자 특징을 분자 전체의 표현으로 모으는 부분, 데이터 전처리와 처리군·대조군 평균 계산, 전체 학습 및 평가 코드는 이 예시에 포함하지 않았습니다. 각 함수의 역할과 입력·출력의 연결을 읽어 보기 위한 예시입니다.
