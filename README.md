## Intro

현재 건국대학교 융합생명공학과에 재학 중이며, 2027년 2월 졸업 예정입니다.

융합생명공학을 전공하지만, 파이썬을 활용한 데이터 분석과 인공지능 관련 교양 수업 및 EECS 498-007과 CS229 등 유튜브 강의를 통해 딥러닝과 머신러닝에 대해 공부하며, 인공지능과 계산생물학에 꾸준히 관심을 가져왔습니다. 또한 AI의 발전으로 코드 구현에 대한 진입 장벽이 낮아지면서 바이오 AI를 본격적으로 
구현해보기 시작했습니다.

현재는 분자 구조를 이용한 약물 반응 예측과 조직별 모델을 연결하는 인체 디지털 트윈에 관심을 두고 있습니다. 바이오 데이터를 활용해 치료와 연구에 도움이 되는 인공지능 모델을 설계하고 싶습니다.
