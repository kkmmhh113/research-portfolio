# 코드 검증 기록

2026년 9월 14일에 검토했습니다. 공개 코드의 수치 구현 검증과 과거 성능에 대한 근거를 구분해 기록합니다.

| 검증 항목 | 결과 |
| --- | --- |
| 약물 반응 예측 패키지 테스트 | 117개 통과 |
| 조직 모델링 패키지 테스트 | 133개 통과 |
| Wheel 패키지 빌드 및 별도 폴더 설치 | 두 패키지 모두 통과 |
| 설치한 하위 모듈 불러오기 | 70개 통과 |
| 분자 특징 추출 예제 | 에탄올의 분자 지문 2,048차원과 분자 기술자 8차원 추출 |
| 합성 PBPK 예제 | 시간점 49개, 최대 질량 오차 약 2.84 × 10⁻⁹ mg, 최소 상태 물질량 0 mg |

테스트와 예제는 macOS에서 Python 3.13, PyTorch 2.11.0, RDKit 2026.3.4, NumPy 2.4.4, pandas 2.3.3, SciPy 1.17.1, PyYAML 6.0.3, PyArrow 25.0.0, pytest 9.1.1을 사용해 실행했습니다. 저장소의 자동화 워크플로는 Linux와 Python 3.11 환경에서도 포함된 테스트와 예제를 실행합니다. 최신 실행 결과는 GitHub Actions에서 확인할 수 있습니다.

위 결과는 이번에 선별해 공개한 소스의 테스트이며, 원래 연구 작업 공간에 있던 모든 테스트를 포함하지는 않습니다. 벤치마크 학습이나 따로 보관한 테스트 세트의 평가는 다시 실행하지 않았습니다. DermaMNIST 노트북의 별도 검증 한계는 해당 [프로젝트 페이지](../projects/dermamnist/README.md)에 설명했습니다.

## 공개 코드 정리 기준

- 기존 모듈 이름, 수치 계산 로직, 검증 절차, 가정이나 수치 계산의 세부 사항을 설명하는 유용한 주석을 유지했습니다.
- 매개변수 설정에 과학적 출처를 남기고, 중복되는 인라인 주석 하나를 제거했습니다. 원본과 공개 Python 코드의 구문 트리를 비교해 복사한 수치 코드가 바뀌지 않았음을 확인했습니다.
- 모델, 재사용 가능한 분석 함수, 대표적인 학습·추론 도구, 관련 설정, 독립적으로 실행할 수 있는 테스트를 포함했습니다.
- 원본 데이터셋, 학습된 가중치, 개인 및 원격 서버 설정, 비공개 작업 자동화 도구, 캐시 파일, 논문 생성 도구, 내부 작업 메모는 제외했습니다.

현재 소스에는 후속 개발 코드가 포함되어 있습니다. 모든 과거 결과를 산출한 정확한 구현 버전이라고 주장하지 않습니다. 과거 지표와 그 한계는 각 프로젝트의 평가 기록에 남겨 두었습니다.
